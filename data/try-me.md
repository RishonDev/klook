# Quick Look

This is how **klook** shows a Markdown file. Change the style in
*System Settings → Apps & Windows → Quick Look* and press *Try it* again.

## Keys

- **Space** or **Esc**: close
- **← / →**: previous / next file in the folder
- **Enter**: open with the default app

## Code

Inline code like `klook --next` is shaded, and so are blocks:

```sh
klook README.md
klook --settings
```

> Press Space on any file in Dolphin to preview it.
